# 🏠 House Price Prediction Using Machine Learning

## Overview

This project predicts house prices using Machine Learning algorithms by analyzing various housing features such as location, number of bedrooms, bathrooms, area, parking, furnishing status, and more.

The project includes:

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Model Saving
- House Price Prediction

---

## Dataset

The dataset contains information about residential houses.

Example Features:

- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

Target:

- Price
